# Ordenação de Transações — Merge Sort x Quicksort x Heapsort

Aplicação console em C# que:
- gera um array `Transacao[]` aleatório (semente fixa = resultados reproduzíveis);
- ordena **clones** do mesmo array com Merge Sort, Quicksort e Heapsort, usando `Valor` como chave;
- mede o tempo de cada algoritmo com `Stopwatch`;
- confere se o resultado está ordenado;
- exibe as **10 maiores transações** (os 10 últimos elementos após a ordenação crescente).
